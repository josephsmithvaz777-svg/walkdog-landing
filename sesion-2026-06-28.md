## 5. Culqi — diagnóstico y solución ✅



### Arquitectura de checkout



```

walkdogentrena.com/checkout.html     →  página estática (landing)

formacion.walkdogentrena.com         →  Laravel API + plataforma

  GET  /api/landing/config

  POST /api/landing/checkout

```



**El checkout HTML va en el hosting de la landing, no en Laravel.**



### Flujos por plan



| Plan | Precio | Flujo Culqi backend |

|------|--------|---------------------|

| START | $50 | `POST /charges` (cargo directo) — si `billing_period: once` |

| CONTROL | $100/mes | `GET /recurrent/plans` → `POST /cards` → `POST /recurrent/subscriptions/create` |

| ELITE | $1000/año | Igual que CONTROL |



> En Laravel los tres planes están como suscripción mensual/anual por ahora; START en landing dice "único" — pendiente alinear `billing_period: once` si se confirma el modelo de negocio.



### Error observado



| Paso | Resultado |

|------|-----------|

| Token tarjeta en CulqiPanel | **201** ✅ |

| `GET /v2/plans?limit=100` | **400** ❌ |

| UI checkout | 422 — *"Culqi rechazó la consulta de planes"* |



### Causa real (no era la llave ni el panel)



Culqi movió la API de recurrencia. El endpoint antiguo `/v2/plans` devuelve **400** aunque `CULQI_SECRET_KEY` sea correcta. El endpoint válido es:



```

GET https://api.culqi.com/v2/recurrent/plans?limit=100   → HTTP 200 ✅

```



Verificación en servidor (tinker):



```

plan-ba-2026  => pln_test_ETfhKA5317a8Xw1z

plan-int-2026 => pln_test_Gm79DNul6jckD833

plan-pre-2026 => pln_test_50ykHqMV9I4waWTU

```



En CulqiPanel solo aparece el **código de plan** (`plan-ba-2026`); el `pln_test_…` se obtiene por API o al crear el plan.



### Fix aplicado (`CulqiService.php`)



| Antes (roto) | Después (correcto) |

|--------------|-------------------|

| `GET /plans` | `GET /recurrent/plans` |

| `POST /subscriptions` | `POST /recurrent/subscriptions/create` + `tyc: true` |

| `DELETE /subscriptions/{id}` | `DELETE /recurrent/subscriptions/{id}` |



También: GET sin `Content-Type: application/json`; `extractError()` con mensajes claros.



### Onboarding de planes en Culqi



| Plan | URL onboarding | `culqi_onboarding_id` |

|------|----------------|----------------------|

| START | `…/onboarding?id=bdabc32e-316d-4663-b7c6-7ae54f51bfc1` | `bdabc32e-316d-4663-b7c6-7ae54f51bfc1` |

| CONTROL | `…/onboarding?id=fc4577f0-bb79-4a7b-979d-958219fb4b9c` | `fc4577f0-bb79-4a7b-979d-958219fb4b9c` |
