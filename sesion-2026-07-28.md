## 1. Wordmark WALKDOG

Texto decorativo grande al pie del footer, inspirado en un footer tipo “CONVRTO”.

### Estructura

- Elemento: `<p class="site-footer__wordmark" aria-hidden="true">WALKDOG</p>`
- Ubicación: dentro de `.site-footer`, **fuera** de `.site-footer__inner` / `.container`, para ocupar todo el ancho
- Color: amarillo de marca (`--warm-start` / `#ffd00d`)
- Tipografía: display, weight 900, mayúsculas
- Tamaño desktop: `clamp(4.25rem, 22vw, 17.5rem)`
- Tamaño móvil: `clamp(3.1rem, 24vw, 6.5rem)`

### Fade lateral (desktop)

Degradado con `background-clip: text`:

```
#000 0% → #000 8% → amarillo 28% → amarillo 72% → #000 92% → #000 100%
```

| Zona | Porcentaje |
|------|------------|
| Negro puro (izq.) | 0% → 8% |
| Fade a amarillo | 8% → 28% |
| Amarillo sólido | 28% → 72% (~44% del ancho) |
| Fade a negro | 72% → 92% |
| Negro puro (der.) | 92% → 100% |

En móvil: amarillo sólido ~26%–74% (fade un poco más corto).

### Animación shine

- Keyframes: `footer-wordmark-shine`
- Barrido de brillo blanco de derecha a izquierda cada ~3,6 s
- Misma idea que `hero-title-shine` / `frost-text`
- Desactivada con `prefers-reduced-motion`

## 2. Alineación columna de marca

### Problema

La columna `.site-footer__col--brand` (logo, redes, copyright) heredaba el padding global de `section`:

```css
section { padding: clamp(3.5rem, 7vw, 4.5rem) 0; }
```

Las listas sí tenían `padding: 0`, así que el logo quedaba más abajo que los títulos Contáctanos / Explora / Información.

### Solución

Reset en la columna marca:

- `padding: 0 !important`
- `margin: 0 !important`
- `align-self: start`
- `justify-content: flex-start`

El logo queda alineado arriba respecto a las listas.
